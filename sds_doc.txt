2. Database Design
a. Database Schema
  

b. Table Description
No
	Table
	Description
	1
	staff_roles
	Stores internal staff and administrative roles for platform operators (such as Administrator, Content Moderator). Attributes: id, code, name, description, created_at. Primary key: id. Foreign keys: None.
	2
	staffs
	Stores administrator and content moderation accounts. Separated from listener accounts to enforce role-based administrative isolation. Attributes: id, role_id, email, password_hash, full_name, avatar_url, status, last_login_at, created_at, updated_at. Primary key: id. Foreign keys: role_id references staff_roles.id.
	3
	users
	Stores authentication credentials, account status, and registration details for Listeners and Creators. Attributes: id, email, password_hash, status, email_verified_at, last_login_at, deleted_at, created_at, updated_at. Primary key: id. Foreign keys: None.
	4
	user_profiles
	Stores the public and personal profile information associated with a listener account, including username, display name, biography, avatar, date of birth, and country. Attributes: user_id, username, display_name, bio, avatar_public_id, avatar_url, date_of_birth, country_code, created_at, updated_at. Primary key: user_id. Foreign keys: user_id references users.id.
	5
	email_verification_tokens
	Stores hashed one-time tokens used to verify an email address after account registration. A token has an expiration time and can only be used once. Attributes: id, user_id, token_hash, expires_at, used_at, created_at. Primary key: id. Foreign keys: user_id references users.id.
	6
	password_reset_tokens
	Stores hashed one-time tokens used in the forgot-password and reset-password process. A valid token allows the account owner to create a new password before the token expires. Attributes: id, user_id, token_hash, expires_at, used_at, created_at. Primary key: id. Foreign keys: user_id references users.id.
	7
	refresh_tokens
	Stores hashed refresh tokens used to maintain authenticated sessions for both listeners and staff. Attributes: id, user_id, staff_id, token_hash, expires_at, revoked_at, created_at. Primary key: id. Foreign keys: user_id references users.id (Nullable); staff_id references staffs.id (Nullable).
	8
	genres
	Stores music genres used to categorize and filter tracks. Managed by platform administrators without removing existing track relationships. Attributes: id, name, slug, description, is_active, created_by_user_id, created_at, updated_at. Primary key: id. Foreign keys: created_by_user_id references staffs.id.
	9
	albums
	Stores albums, EPs, and singles created by registered listeners/creators. Contains album metadata, publication status, cover references, release date, and publication time. Attributes: id, created_by_user_id, title, slug, description, status, cover_public_id, cover_url, release_date, published_at, created_at, updated_at. Primary key: id. Foreign keys: created_by_user_id references users.id.
	10
	tracks
	Stores track metadata, publication status, playback information, and references to audio and cover files hosted on Cloudinary. Attributes: id, uploader_user_id, album_id, genre_id, title, slug, description, track_number, publication_status, approved_at, latest_rejection_reason, audio_public_id, audio_url, audio_format, duration_ms, cover_public_id, cover_url, play_count_cache, created_at, updated_at. Primary key: id. Foreign keys: uploader_user_id references users.id; album_id references albums.id (ON DELETE SET NULL, Nullable); genre_id references genres.id.
	11
	track_submissions
	Stores each request to submit a track for Staff moderation review. Records submitter, reviewer staff, submission status, notes, rejection reason, and timestamps. Attributes: id, track_id, submitted_by_user_id, reviewer_staff_id, status, submitter_note, reviewer_note, rejection_reason, submitted_at, reviewed_at. Primary key: id. Foreign keys: track_id references tracks.id; submitted_by_user_id references users.id; reviewer_staff_id references staffs.id.
	12
	official_lyrics
	Stores official time-synchronized lyrics for published tracks. Managed and maintained by platform Staff across supported language translations. Attributes: id, track_id, language_code, lyric_content, status, created_by_staff_id, created_at, updated_at. Primary key: id. Foreign keys: track_id references tracks.id; created_by_staff_id references staffs.id.
	13
	personal_lyrics
	Stores private lyrics, translations, or transliterations created by listeners for specific tracks. Personal lyrics are strictly private to the creator account. Attributes: id, user_id, track_id, language_code, lyric_content, created_at, updated_at. Primary key: id. Foreign keys: user_id references users.id; track_id references tracks.id.
	14
	listening_history
	Stores valid playback events for authenticated listeners. Records the selected track, playback time, listened duration, and completion status. Attributes: id, user_id, track_id, listened_duration_ms, completed, played_at. Primary key: id. Foreign keys: user_id references users.id; track_id references tracks.id.
	15
	favorites
	Represents the many-to-many relationship between users and their favorite tracks. The composite primary key prevents duplicate favorites. Attributes: user_id, track_id, created_at. Primary key: user_id, track_id. Foreign keys: user_id references users.id; track_id references tracks.id.
	16
	playlists
	Stores playlists created by registered listeners. Contains playlist name, description, visibility, cover references, owner, and modification times. Attributes: id, owner_user_id, name, description, visibility, cover_public_id, cover_url, created_at, updated_at. Primary key: id. Foreign keys: owner_user_id references users.id.
	17
	playlist_tracks
	Represents the many-to-many relationship between playlists and tracks, storing playback position and the adding user. Attributes: playlist_id, track_id, added_by_user_id, position, added_at. Primary key: playlist_id, track_id. Foreign keys: playlist_id references playlists.id (ON DELETE CASCADE); track_id references tracks.id (ON DELETE CASCADE); added_by_user_id references users.id.
	18
	content_reports
	Stores violation reports submitted by listeners against published tracks for Staff processing. Records category, description, status, assigned Staff member, and resolution. Attributes: id, track_id, submitted_by_user_id, handled_by_staff_id, category, description, status, resolution_note, created_at, handled_at, updated_at. Primary key: id. Foreign keys: track_id references tracks.id; submitted_by_user_id references users.id; handled_by_staff_id references staffs.id.
	19
	notifications
	Stores in-application notifications sent to registered accounts (both listeners and staff) for review results, report resolutions, and alerts. Attributes: id, user_id, staff_id, type, title, message, action_url, read_at, created_at. Primary key: id. Foreign keys: user_id references users.id (Nullable); staff_id references staffs.id (Nullable).

	AuthenticationService Class
No
	Method
	Description
	1
	login(LoginRequest request)
	Inputs: Login request DTO containing user email, raw password, rememberMe option, and portal context. Outputs: LoginResult record encapsulating AuthResponse, raw refresh token string, and cookie expiration lifetime in seconds. Internal processing: Normalizes target email address, inspects Staff repository for administrative access, queries public User repository, validates password hash via BCrypt encoder, checks account lockout and rate-limiting status, ensures account active status and email verification, updates last login timestamp, persists new RefreshToken session, generates signed JWT access token, and builds LoginResult.

	Inputs: User entity instance. Outputs: Void. Internal processing: Verifies that the user account status is not BANNED, confirms the account has not been soft-deleted, checks that temporary lock has not expired or is not currently active, and asserts that the user status is ACTIVE and email has been verified. d. Database Queries
* Retrieve public user account by email address (case-insensitive and not deleted):
sql
SELECT u.id, u.email, u.password_hash, u.status, u.locked_until, u.email_verified_at, u.deleted_at
FROM users u
WHERE LOWER(u.email) = LOWER(:email)
 AND u.deleted_at IS NULL;
* Check staff account for portal isolation check (case-insensitive and not deleted):
sql
SELECT s.id, s.email, s.password_hash, s.status, s.role_id, s.deleted_at
FROM staffs s
WHERE LOWER(s.email) = LOWER(:email)
 AND s.deleted_at IS NULL;
* Update user last login timestamp and reset expired temporary lockout:
sql
UPDATE users
SET last_login_at = timezone('UTC', CURRENT_TIMESTAMP),
   status = 'ACTIVE',
   locked_until = NULL,
   updated_at = timezone('UTC', CURRENT_TIMESTAMP)
WHERE id = :userId;
* Retrieve user display name and avatar URL from profile:
sql
SELECT up.display_name, up.avatar_url
FROM user_profiles up
WHERE up.user_id = :userId;
* Insert new Refresh Token record for active session:
sql
INSERT INTO refresh_tokens (
   user_id, token_hash, expires_at, created_at
) VALUES (
   :userId, :tokenHash, :expiresAt, timezone('UTC', CURRENT_TIMESTAMP)
);

No
	Method
	Description
	1
	verifyEmail(EmailOtpRequest request)
	Inputs: EmailOtpRequest containing user email and submitted OTP string. Outputs: MessageResponse confirming activation. Internal processing: Validates token state (rejecting already used or expired tokens); checks OTP match using PasswordEncoder.matches; on mismatch, increments failed attempts counter in AuthRateLimiterService; if maximum threshold (5 attempts) is reached, executes lockout callback marking token deactivated; otherwise raises exception indicating remaining attempts.

d. Database Queries
